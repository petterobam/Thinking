# 五种思考模式

一个模式 = 一条**采集 → 多轮追问 → 收敛**的流水线。
"轮数"是硬要求：每一轮必须有明确的新问题，并留下**一句话的轮次结论**。
轮次结论要写进临时笔记（例如 `/tmp/notebook-<date>.md`），第 5 步的旅程直接从它长出来。

**本次走几轮是可配置的**：先跑 `assets/rounds.sh` 拿到这张运行的计划轮数（环境变量 / `config.env`，
见 SKILL.md 第 2 节）。下面每个模式标的「默认 N 轮」是**没有配置时**的值，不是上限也不是下限。

除内置的 A–E，用户还可以在 `sources.conf` 里配**自定义思考方向**（F、G…，读他自己的笔记 / 知识库）。
自定义方向的轮次题目：有 `rounds_template` 就按它；没有就用下面的「通用加轮池」自己出题。
完整规则见 `04-custom-directions.md`。

跨模式的通用约束：

- 一轮 = 一个新视角 + 一个新结论。同义反复不算轮。
- 至少有一轮要**自我反驳**：如果你的结论是 A，那就认真替非 A 辩护一次。
- 至少有一轮要**落地**：找一个具体的人、具体的数量、具体的时间。
- 收敛时如果发现"只能写出一句正确的废话"，就换模式，不要硬写。

### 轮数比模板多

先按该模式的**加轮表**顺序追加；加轮表用完了，再从**通用加轮池**按顺序取。

**通用加轮池**（任何模式都能用）

1. **尺度轮**：这件事从个人放大到组织、再缩回一个人，哪一层的答案最锋利？
2. **十年轮**：十年后回看今天，什么会显得可笑，什么会变成常识？
3. **证伪轮**：找一个能推翻当前结论的真实例子；找不到，也要说清为什么找不到。
4. **命名轮**：给这个还没有名字的现象起一个准确的名字（不许用现成术语）。
5. **代价轮**：为了让这个结论成立，我正在放弃什么？

### 轮数比模板少

按这个顺序删：① 先删标着**（可选）**的轮；② 还不够就**从后往前**删模板轮；
③ **必留轮**（每个模式单独标注）和下面两条永远不能删：

- 至少一轮**自我反驳**（替相反的结论辩护一次）
- 至少一轮**落地**（具体的人 / 数字 / 时间）

所以最少是 2 轮——再少就不是"想"，只是"写"。

每一轮的结论都带编号写进轮次笔记：`A4 · 时间轮：……`，编号以 `rounds.sh` 的输出为准。

## A · 📰 时事沉思（默认 4 轮 · 可调）

**必留轮**：事实轮、自我轮 ｜ **加轮表**：6 镜像轮（同一件事在另一个国家/行业的版本，差在哪）→ 7 账本轮（我自己这个月为它花了多少钱、多少分钟）→ 8 停摆轮（如果这个变化明天停止，谁最受伤）

从正在发生的公共讨论里，提炼社会意识的切片。

**材料**（至少 2 个不同倾向的来源，同一事件）
- `web.search` / 浏览器搜索当天或本周的头条、热榜、行业报道。
- 优先找**数字**：钱、时长、人数、比例、罚款、工资。
- 找**被忽视的一方**：没有发言权的人（骑手、审核员、被裁者、用户、供应商）。

**轮次模板**
1. **事实轮**：这件事里最确凿的一个数字是什么？它改变了什么？
2. **利益轮**：谁在这个变化里赚到，谁在付出？付出的人知道自己在付吗？
3. **时间轮**：把时间尺度拉到十年后，今天的新闻会变成什么常识？
4. **自我轮**：我自己是不是也在参与它？我付的是什么？
5. （可选）**反方轮**：如果我是决策者/受益者，我会怎么辩解？这个辩解哪里是真的？

**常见失败**
- 变成时评或道德审判（"平台太贪婪了"）——箴言不是判决书。
- 复述新闻标题当见解。
- 只写宏大叙事，没有具体的人。

**输出标准**：箴言应当让读者重新看一眼自己每天都在做的一件小事。
**示例方向**：注意力被谁定价、免费服务的账本、城市里被算法计时的身体。

## B · 🧭 会话回望（默认 3 轮 · 可调）

**必留轮**：形状轮、可迁移轮 ｜ **加轮表**：5 复盘轮（如果重来一次，我第一句话会换成什么）→ 6 他人轮（同事/用户会怎么描述今天这个问题）→ 7 无损轮（这个形状在我不用写代码的生活里出现在哪）

回看用户**今天真实做过的事**：任务、调试、对话、会议、代码。

**材料**
- `git log --since="24 hours ago" --stat`（本仓库与用户指定仓库）
- 用户当天的会话记录 / 待办 / 会议纪要（用户指到哪里就读到哪里）。
- 反复出现的报错、反复修改的同一个文件、一次"终于跑通"的瞬间。

**轮次模板**
1. **形状轮**：今天这个问题到底是什么形状？（是信息缺失？是依赖太多？是命名错了？是目标本身错了？）
2. **代价轮**：我们为它付出的时间和情绪，其中多少是因为问题本身，多少是因为我们没承认问题的形状？
3. **可迁移轮**：换一个完全不同的领域（写小说、做饭、谈恋爱），同一句话还成立吗？把不成立的版本删掉。
4. （可选）**未来轮**：如果明天再遇到同形状的问题，我会先说哪一句话？

**常见失败**
- 写成工作总结（"今天完成了三个需求"）。
- 技术黑话外溢，非同行读不懂。
- 箴言里出现框架名、函数名、公司名。

**输出标准**：一个不写代码的人读完，能把它套到自己今天遇到的某个卡点上。

## C · 🕯️ 悬问求索（默认 5 轮 · 可调）

**必留轮**：定义轮、对立轮 ｜ **加轮表**：7 语言轮（别的语言/古人有没有更准的词，它的边界在哪）→ 8 孩童轮（用一个孩子的问法把问题重问一遍）→ 9 复现轮（这个问题会不会每一代人都重新问一次，为什么）

挑一个**这个仓库从未想过**的问题。难度最高，也最容易出好卡片。

**怎么挑问题**（三选一）
- 从旧卡里找**缝隙**：某张卡说的反面是什么？
- 从常识里找**没人问的前提**：为什么钥匙要转两圈？为什么道歉要先说"我不是那个意思"？
- 从反常识陈述起步：先把一句话反过来说，再认真论证它为什么可能对。

**轮次模板**（递进，不许平行）
1. **定义轮**：这个问题里的核心词，能不能给它一个更精确的定义？
2. **重述轮**：把问题改写成另一种说法，看它是否还成立。
3. **边界轮**：找一个它不成立的极端例子。
4. **对立轮**：替相反的立场辩护一次。
5. **收敛轮**：在所有版本里，哪一句最经得起十年？
6. （可选）**经验轮**：我自己有没有一次真实的经历，能证明或推翻它？

**常见失败**
- 问题太大（"什么是幸福"）→ 必须切小到"今天中午为什么不想吃饭"。
- 变成哲学名词的堆叠。
- 追到一半忘了起点，卡与问题脱钩。

**输出标准**：读者读完会有一种"啊，原来这个问题还可以这样问"的轻微失重感。

## D · 🌿 生活即景（默认 3 轮 · 可调）

**必留轮**：画面轮、反转轮 ｜ **加轮表**：5 第二细节轮（同一天、同一质地的另一个细节，两个是否指向同一件事）→ 6 缺席轮（这个画面里本该出现却不在的东西）→ 7 叙述者轮（换一个在场的人来讲，他会先说什么）

从一个**感官细节**出发：声音、温度、气味、光影、手上的触感。

**材料**：今天的通勤、晚餐、雨、楼道的灯、便利店店员的一句话、手机相册、聊天记录里的一句闲话。
没有材料就直接问用户："今天有没有一个瞬间让你停了半秒？"

**轮次模板**
1. **画面轮**：只写看得见的东西，不写感受（"电梯里第三层进来的人撑着一把滴水的伞"）。
2. **联想轮**：这个画面让你想起哪一个更大的东西？（时间、陌生人之间的契约、城市的湿度）
3. **反转轮**：如果这个细节有意图，它在做什么？
4. （可选）**告别轮**：如果这是最后一次看到它，我想说什么？

**常见失败**
- 抒情过度（"啊啊，岁月啊"）。
- 只有景没有人，或只有情绪没有物。
- 把生活小事强行升华成人生大道理。

**输出标准**：具体的细节撑起抽象的落点，两者之间不要有桥墩多余的解释。

## E · 📖 旧笺重读（默认 3 轮 · 可调）

**必留轮**：重读轮、和解轮 ｜ **加轮表**：5 时间戳轮（把新旧两张卡按时间排开，中间发生了什么）→ 6 反卡轮（替旧卡写一段反驳现在的我的话）→ 7 第三句轮（新旧两句能不能压成更好的第三句）

重读仓库已有卡片，与过去的自己辩驳。**必须引用旧卡的 slug**。

```bash
ls content/cards | tail -20
node scripts/validate.mjs          # 顺带看模式分布，挑一个少写的模式
```

**轮次模板**
1. **重读轮**：那张旧卡今天还成立吗？哪一句现在读起来刺眼？
2. **变化轮**：这中间发生了什么，让我变了？
3. **和解轮**：是旧的我错，还是新的我变软了？给出证据。
4. （可选）**补刀轮**：给旧卡补一句它当年不敢说的话。

**常见失败**
- 直接改写旧卡（造成内容重复，校验会报错）。
- 只是换个说法重复旧观点。
- 把"反思"写成情绪宣泄。

**输出标准**：两张卡并排放在一起，读者能看见一个思想在时间里生长的痕迹。

## 模式选择建议

| 情境 | 推荐 |
| --- | --- |
| 用户说"最近有什么新闻/社会"，或今天有重大公共事件 | A |
| 用户刚结束一段密集工作、调试、讨论 | B（材料最真，成功率高） |
| 用户说"随便想点什么"，或想跳出舒适区 | C |
| 材料很少、心很安静、或用户想放松 | D |
| 仓库已有 20 张以上卡片 | E（保持思想的自洽性） |

混合使用示例：**B + C**（今天调试里出现的一个问题，追成普遍问题），**A + D**（新闻里的数字，对照我桌上的一个物件）。
