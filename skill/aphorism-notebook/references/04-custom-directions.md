# 自定义思考方向（用户的知识库 / 笔记）

内置的 A–E 想的是"世界"，自定义方向想的是**用户自己的东西**：Obsidian / 思源 / Logseq 仓库、
notes 目录、书摘、访谈稿、剪藏、某个项目的 `git log`、某个领域的资料库。

一个自定义方向 = `sources.conf` 里的一段 `[代号]`：名字 + 素材路径 + 默认轮数 + 挖掘提示（可选）。

---

## 一、什么时候要动它

| 时机 | 动作 |
| --- | --- |
| **首次运行**，`sources.conf` 不存在或没有任何方向 | 主动问一句（照抄下面的问话），别自作主张扫用户硬盘 |
| 用户说"把我的笔记/知识库加进来""再给一个方向" | `sources.sh add` |
| 用户说"路径变了""改成 6 轮""换个说法" | `sources.sh set` |
| 用户说"删掉那个方向" | `sources.sh remove` |
| 用户说"今天没什么好写的""翻翻我自己的东西" | 优先读自定义方向的素材 |

单张卡片最多混两个方向（例如 `B + F`，或自定义方向单独用）。

---

## 二、首次运行的问话（照抄，别改写成一长串）

> 你有没有想让卡片去读的东西？比如某个笔记仓库、某个 notes 目录、一本书的摘录、某个项目的 git log。
> 说个路径就行，我把它配成一个专属的思考方向。
> 先不用也完全没问题，以后随时可以加。

- 用户给了路径 → 走第三节命令添加，然后把 `assets/rounds.sh` 的输出给他看一眼。
- 用户说"先不用" → 别追问，继续写卡片；之后他想加随时说。

---

## 三、命令（都相对 skill 目录）

```bash
S=~/.codex/skills/aphorism-notebook/assets/sources.sh

bash "$S" list                                   # 看当前有哪些方向
bash "$S" add --name 旧笔记考古 --paths '~/Notes,~/vault' --rounds 5 \
             --hint '先看最近 7 天改动过的笔记'     # 代号自动分配（F 起）
bash "$S" add --interactive                       # 逐项问（首次安装/用户想边问边填）
bash "$S" set F paths '~/Notes/2026,~/vault'      # 改字段：name/paths/rounds/emoji/hint/rounds_template
bash "$S" set F rounds 6
bash "$S" remove F                                # 删除（会直接改文件，先跟用户确认）
bash "$S" check                                   # 校验：代号、必填字段、轮数范围、路径可达性
bash "$S" init                                    # 没有配置文件时建一份带注释的模板
```

注意事项：

- **代号**是一个大写字母；`A–E` 是内置模式，自定义方向从 `F` 开始，脚本会自动挑空位。
  用户如果想用某个字母（"叫 K 吧"），可以 `add --code K`。
- **路径**逗号分隔，支持 `~`、目录、单个文件、`*` 通配。加完脚本会逐个打勾/打叉——
  读不到的路径只提醒，不拦，但要在汇报里跟用户说一声。
- 用户改完配置，**跑一次 `bash <skill-dir>/assets/rounds.sh`** 把新的轮数表贴给他看一眼。
- 用户临时说"今天这条想深一点" → 用对话覆盖，不要改配置文件。

## 四、读素材的硬要求

1. **真的打开读**：`ls -lt`、`sed -n`、`rg`、`git log` 都行，就是不许凭印象写。
2. **先筛再读**：几百上千个文件的目录，先按最近改动或名字挑 5–10 个，不要地毯式全读。
3. **能说出出处**：卡片或汇报里至少要有一个具体的文件名、笔记标题、日期或原话——这是"我真的读了"的证据。
4. **别抄原句**：笔记里的话是材料，不是箴言。压成十来字的那句话必须是你想出来的。
5. **隐私红线**：卡片会推到**公开仓库**。密码、客户名、同事真名、未公开的项目细节、
   私人对话一律不写；要么不用，要么抽象到只剩形状（"某个上线的夜里"而不是"某某项目 3 月 14 日事故"）。
6. 素材里出现别人的观点、书里的句子 → 不许当自己的箴言；可以当起点，但要写清是"读到 X 让我想到 Y"。

## 五、轮次怎么算

- `sources.conf` 里 `rounds=N` 是这个方向**不配置思考强度时**的默认轮数（2–12，默认 4）。
- 思考强度档位对它同样生效：`light` 在它的默认值上 −1，`deep` +2，`max` +4；
  也可以用 `APHORISM_THINKING_ROUNDS=F=8` 精确指定某个自定义方向。
- 有 `rounds_template`（用 `|` 分隔的轮次题目）就按它走；没有就按默认轮数，从
  `00-thinking-modes.md` 的「通用加轮池」里取题，并保持两条通用约束：
  至少一轮自我反驳、至少一轮落到具体的人/数字/时间。

## 六、常见失败

- ❌ 说"我读了你的笔记"，却说不出一个文件名。
- ❌ 把用户笔记的原句直接当箴言（那是引文，不是卡片）。
- ❌ 路径读不到还硬编内容（先问用户，或这一张先不用这个方向）。
- ❌ 把隐私素材原样写进公开站点。
- ❌ 未经确认就 `remove`（删之前先复述一遍是哪个方向，让用户点头）。
- ❌ 一次读遍整个知识库，把上下文烧光（先筛，再读）。
