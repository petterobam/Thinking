# 发布前清单

逐条打勾，任何一条不通过就回去改。

## 材料
- [ ] 这张卡由一个**今天真实发生**的东西触发（新闻 / 日志 / 报错 / 一段对话 / 一个画面）
- [ ] 我能说出它的具体来源（一句话就能说清）
- [ ] 走了自定义思考方向的话：我真的打开读过文件，说得出文件名 / 笔记标题 / 日期
- [ ] 素材里没有不能公开的内容（客户名、私人对话、未公开的项目细节）

## 思考
- [ ] 达到了本次 `assets/rounds.sh` 解析出的轮数（把那张表贴在笔记里，逐轮数得出来）
- [ ] 每一轮都换了视角，且必留轮一个没少
- [ ] 至少有一轮自我反驳，至少有一轮落到具体的人/数字/时间
- [ ] 没有把"同一句话说三遍"当作三轮

## 箴言
- [ ] 8–16 字，单行，无句号叹号
- [ ] 能被看见的名词 + 一次转折
- [ ] 删掉两个字还成立吗？我删过了吗？
- [ ] 它让人停半秒吗？停在哪里？
- [ ] 它是"我们"的处境，不只是"我"的心情？
- [ ] 不是鸡汤、不是说教、不是名言复述、和旧卡不重复

## 旅程
- [ ] 2–6 个 `##` 小节，每节只推进一步
- [ ] 第一节是画面，不是议论
- [ ] 至少一个只有当事人知道的细节（时间戳、原话、数字）
- [ ] 有一个短句在长句之后（节奏）
- [ ] 结尾是问题 / 承认 / 动作，不是升华口号
- [ ] 全文 120–900 字，读起来像散文，不像报告

## 发布
- [ ] `node scripts/validate.mjs --strict` 通过
- [ ] commit 信息：`card: <slug> — <箴言>`
- [ ] 推送后 `gh run list --limit 1` 看到工作流在跑
- [ ] 向用户报告了卡片、模式、链接
